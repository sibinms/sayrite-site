# Sayrite website

The public page for Sayrite, a dictation app for Mac: click the mic in any
text box (or hold a key), speak, and polished text appears.

**Site:** https://sibinms.github.io/sayrite-site/

**Download:** [Sayrite.dmg](https://github.com/sibinms/sayrite-site/releases/latest/download/Sayrite.dmg),
signed with a Developer ID and notarized by Apple. Each release here has the
disk image and its SHA-256.

The page lives in `docs/` and is served by GitHub Pages from the `main`
branch. Questions or problems? [Open an issue](https://github.com/sibinms/sayrite-site/issues).
